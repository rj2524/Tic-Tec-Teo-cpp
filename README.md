# Tic Tac Toe in C++

A simple console-based Tic Tac Toe game built using C++.

This project was created to practice fundamental C++ programming concepts such as arrays, functions, loops, conditionals, and user input handling.

## Features

- Two-player gameplay
- Input validation
- Win detection
- Draw detection
- Console-based interface

## Technologies Used

- C++
- g++

## How to Run

Compile the program:

```bash
g++ main.cpp -o tic-tac-toe
```

Run:

```bash
./tic-tac-toe
```
